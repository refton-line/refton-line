## `ai.mode = ON`

One of the things I focus on is **working effectively with AI**.

Not just asking questions.

Not just generating code.

The important part is choosing the **right prompt for the actual problem**.

```text
problem
   ↓
understand the task
   ↓
choose the right context
   ↓
design the prompt
   ↓
interact with AI
   ↓
evaluate the result
   ↓
iterate
   ↓
better solution
```

### My principle

> **A good prompt is not about saying more.
> It's about giving the model exactly what the task requires.**

I treat AI as a tool for reasoning, exploration, implementation, debugging, and learning — while keeping the final judgment on the human side.

## `testing != failure`

This is probably the idea that describes my approach best:

> **Making mistakes is not a bad thing.**

When you interact with something new for the first time, an incorrect result is often an expected part of the process.

A mistake gives you information:

```text
UNKNOWN
   ↓
TRY
   ↓
ERROR
   ↓
ANALYZE
   ↓
UNDERSTAND
   ↓
ADAPT
   ↓
TRY AGAIN
   ↓
KNOWLEDGE
```

Every unfamiliar system has behavior that has to be discovered.

So instead of asking:

**"Why did I fail?"**

I prefer asking:

**"What did this result teach me?"**

**Electron desktop application · Task Tracker · More than a task tracker**

**Лад** is an Electron-based desktop application built around the idea of a **task tracker — and more**.

The goal is not simply to create another list of tasks.

It's about building a practical environment where tasks, organization, and interaction with the application come together into one desktop experience.

### Concept

```text
┌─────────────────────────────────────┐
│              Л А Д                  │
│                                     │
│   TASKS       ORGANIZATION          │

│          WORKFLOW                  │
│              │                      │
│              ▼                      │
│        LESS FRICTION                │
└─────────────────────────────────────┘
```

The project is also an opportunity to experiment with:

* Electron desktop architecture
* JavaScript-based application logic
* UI/UX decisions
* State and task management
* Iterative development
* Testing ideas in a real application
